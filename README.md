# 🧮 Java Calculator

A simple calculator application built with Java. This project is currently **under development** and serves to practice programming logic, object-oriented principles, and exception handling.

## 🚀 Project Status
⚠️ **In Progress:** The core logic is being built, but the application currently has **many bugs that need to be fixed** before it is stable. New operations and a Graphical User Interface (GUI) will be added in the future.

## 🐛 Known Issues & Bugs
* **Edge Cases:** Some decimal calculations might return imprecise results.
* **State Management:** Multiple consecutive operations without resetting may cause unexpected behavior.

## ✨ Current Features
* **Addition** (+)
* **Subtraction** (-)
* **Multiplication** (*)
* **Division** (/) with validation to prevent division by zero

## 🛠️ Technologies Used
* **Java SE** (Version 17 or higher recommended)
* **Scanner API** for console data input

## 💻 How to Run the Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd your-repository-name
   ```

3. **Compile the main file:**
   ```bash
   javac Main.java
   ```

4. **Run the application:**
   ```bash
   java Main
   ```
